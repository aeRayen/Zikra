## 4. سيناريوهات إلزامية للمنبه والأذان (الحزم 2.4 و2.5 و5.8)

1. جدولة، ثم إعادة تشغيل، **ثم عدم فتح القفل**. يجب أن يرن المنبه.
2. تغيير المنطقة الزمنية يدويًا، وبالسفر المحاكى.
3. الانتقال إلى التوقيت الصيفي وخروجه.
4. وضع Doze لمدة 8 ساعات (`adb shell dumpsys deviceidle force-idle`).
5. رفض صلاحية المنبه الدقيق، فيظهر البديل والتنبيه في الواجهة.
6. رفض صلاحية الإشعارات.
7. إغلاق التطبيق قسرًا (Force stop): يُوثَّق السلوك، لأن النظام يلغي المنبهات.
8. وضع عدم الإزعاج والوضع الصامت.

## 5. اختبارات الخصوصية والأمان

| الاختبار | الأداة |
|---|---|
| لا يصل مستخدم إلى بيانات مستخدم آخر | اختبار تكامل مُولَّد لكل endpoint |
| السجلات وتقارير الأعطال بلا بيانات حساسة | اختبار وحدة لطبقة الإخفاء |
| لا طلبات شبكة عند تعطيل المزامنة | اختبار واجهة مع خادم وهمي يعدّ الطلبات |
| `private.db` لا تُستعاد من النسخ الاحتياطي | اختبار يدوي موثق + فحص القواعد |
| رفض الحزمة المعدلة | اختبار وحدة لكل خطوة في `CONTENT_PACKS_AR.md` §3 |
| فحص الأسرار والتبعيات | gitleaks + OWASP dependency-check / Dependabot |

## 7. بوابة CI لكل طلب دمج

```
android:  assembleDebug assembleRelease lint detekt ktlintCheck testDebugUnitTest
          verifyRoborazziDebug  (Room migration tests ضمن unit tests)
backend:  dotnet build -warnaserror  dotnet test  (Testcontainers)
contract: openapi lint + breaking-change diff against main
data:     apply migrations on empty PostgreSQL 16 container
security: gitleaks  dependency scan
i18n:     no hardcoded strings  ·  ar/en keys complete
```

**لا يُدمج كود إذا فشلت أي خطوة.**
