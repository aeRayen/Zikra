# حدود Android والحماية والخصوصية

## 1. الحماية العادية
يمكن استخدام تصفية DNS أو VPN محلي ضمن متطلبات النظام والسياسات. يجب إظهار حالة الحماية، وشرح سبب طلب الصلاحيات، والتعامل مع انقطاع الشبكة أو توقف الخدمة. قد يتعارض VPN مع تطبيق VPN آخر، وقد لا يمكن تصنيف المحتوى داخل نطاق مشفر مسموح.

## 2. قيود التطبيق العادي
تطبيق عادي لا يملك سلطة مطلقة لمنع المستخدم من:
- إيقافه أو تعطيل بعض صلاحياته.
- إلغاء تثبيته.
- إعادة تشغيل الجهاز أو إعادة ضبط المصنع.
- تغيير الشبكة أو استخدام وسائل بديلة.
- تجاوز الحجب في بعض الحالات.

لا تستخدم صلاحيات مخفية أو وسائل تحايل أو واجهات مضللة لمنع المستخدم من استرداد التحكم بجهازه.

## 3. الوضع المُدار
يمكن إعداد أجهزة مناسبة تحت إدارة Android Enterprise/Device Policy Controller. تختلف السياسات المتاحة وفق نوع الإدارة وإصدار Android والإعداد الأولي. قد يتطلب التهيئة الخاصة مسح الجهاز أو إعداده كجهاز مُدار بالكامل. يجب تقديم شرح وموافقة وإجراءات استرداد واضحة.

Lock Task Mode ليس قفلًا سحريًا لأي تطبيق؛ يحتاج إعدادًا مناسبًا وقائمة تطبيقات مسموح بها وصلاحيات إدارة متوافقة.

## 4. Accessibility
لا تستخدم AccessibilityService إلا إذا كانت وظيفة أساسية مسموحة، مع إفصاح وموافقة صريحة. لا تستخدمها للتجسس أو إخفاء السلوك أو منع الإزالة أو تجاوز آليات أمان النظام.

## 5. المنبه والحساسات
- لا تفترض أن العمل في الخلفية مضمون بلا قيود.
- تحقق من صلاحيات exact alarms حسب إصدار النظام وسياسات المتجر.
- اختبر Doze وتوفير الطاقة وإعادة التشغيل وتغير المنطقة الزمنية.
- لا تعتمد على الحركة وحدها لتأكيد الاستيقاظ.
- لا تجمع الحركة باستمرار طوال الليل إن كانت نافذة تحقق قصيرة تكفي.
- لا تسجل الصوت أو الفيديو سرًا.
- اعرض حالة الصلاحيات والتنبيهات الاحتياطية بوضوح.

## 6. الخصوصية
- البيانات الحساسة محلية افتراضيًا.
- المزامنة اختيارية وبموافقة واضحة.
- لا ترفع سجل التصفح أو تفاصيل الانتكاسات افتراضيًا.
- لا ترسل نصوصًا حساسة إلى أنظمة تحليلات الأخطاء.
- قدم تصديرًا وحذفًا للبيانات.
- وضح الاحتفاظ بالنسخ الاحتياطية ومدة زوال البيانات بعد طلب الحذف.

## 7. أمن الخادم
- TLS.
- تحقق من الهوية والصلاحيات في الخادم.
- فصل صلاحيات الخدمات.
- عدم فتح قاعدة البيانات للإنترنت.
- أسرار خارج Git.
- نسخ احتياطية مشفرة وخارج الخادم.
- مراقبة وتنبيه واختبار استعادة.
- تحديثات دورية وفحص للتبعيات.
- مراجعة أمنية قبل الإطلاق.
