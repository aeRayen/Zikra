# حزمة مشروع Islamic Life OS — دليل البدء

هذه الحزمة هي وثيقة تأسيسية شاملة لتوجيه وكيل ذكاء اصطناعي برمجي لبناء تطبيق إسلامي متكامل. الاسم **Islamic Life OS** مؤقت ويمكن تغييره.

## محتويات الحزمة

- `prompts/MASTER_BUILD_PROMPT_AR.md`: البرومبت الرئيسي الذي يُعطى لوكيل البرمجة.
- `docs/PROJECT_REQUIREMENTS_AR.md`: الرؤية والمتطلبات الوظيفية.
- `docs/ANDROID_REALITY_AND_SECURITY_AR.md`: حدود أندرويد والحماية والخصوصية.
- `docs/ROADMAP_AND_ACCEPTANCE_AR.md`: مراحل التطوير ومعايير القبول والاختبارات.
- `architecture/SYSTEM_ARCHITECTURE.md`: المعمارية المقترحة.
- `database/initial_schema.sql`: مخطط SQL مبدئي قابل للمراجعة والتطوير.
- `database/feature_registry.json`: سجل منظم للوحدات والميزات.
- `design/DESIGN_SYSTEM_AR.md`: اتجاه التصميم وتجربة الاستخدام.
- `design/concept_assets/`: صور SVG مفاهيمية أصلية للوحة الرئيسية، والمصحف، والحماية، والمنبه. هذه نماذج توضيحية وليست لقطات نهائية من التطبيق.
- `prompts/AI_AGENT_WORKFLOW_AR.md`: طريقة تشغيل وكيل البرمجة على مراحل دون أن يحاول بناء كل شيء دفعة واحدة.

## تعليمات الاستخدام

1. فك ضغط الملف.
2. افتح المشروع البرمجي الذي سيبنيه وكيل الذكاء الاصطناعي، أو أنشئ مستودعًا جديدًا.
3. أعطِ الوكيل ملف `prompts/MASTER_BUILD_PROMPT_AR.md` كاملًا، واطلب منه قراءة بقية الملفات المشار إليها قبل كتابة الكود.
4. اجعله يبدأ بمرحلة التدقيق والتخطيط فقط، ثم يطلب اعتمادك قبل تنفيذ التغييرات الكبيرة.
5. نفّذ مرحلة واحدة في كل مرة، واطلب تشغيل الاختبارات وإرفاق تقرير بالملفات التي تغيّرت.
6. لا تضع مفاتيح API أو كلمات مرور أو أسرار خادم داخل المستودع.

## بخصوص الصور

الصور التي ظهرت سابقًا داخل المحادثة كانت صورًا توضيحية مرتبطة باستعلامات صور، وليست ملفات مصدر يمكن استرجاعها من الرد السابق كملفات أصلية. لذلك تضم هذه الحزمة أصول SVG مفاهيمية أصلية يمكن فتحها أو تعديلها أو استبدالها لاحقًا. لا تدّعي الحزمة أنها تحتوي على ملفات الصور المؤقتة التي عُرضت في واجهة المحادثة.

## قرار معماري مهم

ابدأ بتطبيق Android أصلي باستخدام Kotlin وJetpack Compose، وخادم خاص بوحدة Backend واحدة منظمة (Modular Monolith)، وPostgreSQL. صمّم الوحدات كلها من البداية، لكن نفّذها على مراحل. لا تدّعِ أن أي تطبيق أندرويد عادي يستحيل حذفه أو تعطيله.
