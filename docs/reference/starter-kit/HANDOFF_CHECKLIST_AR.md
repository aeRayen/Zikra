# قائمة تسليم المشروع لوكيل الذكاء الاصطناعي

- [ ] قرأت جميع الملفات داخل `docs/` و`architecture/` و`database/` و`design/`.
- [ ] فحصت المستودع الحالي قبل إجراء تغييرات.
- [ ] قدمت تقرير مرحلة التخطيط قبل كتابة كميات كبيرة من الكود.
- [ ] اخترت تقنية Backend واحدة وشرحت السبب.
- [ ] أنشأت `.env.example` دون أسرار حقيقية.
- [ ] وثقت أوامر البناء والاختبار.
- [ ] لم أضع أزرارًا وهمية في شاشات الإنتاج.
- [ ] لم أستخدم بيانات قرآنية/حديثية غير موثقة.
- [ ] لم أدّعِ استحالة حذف التطبيق أو تجاوز الحماية.
- [ ] اختبرت الصلاحيات والخصوصية والنسخ الاحتياطي.
- [ ] نفذت مرحلة واحدة فقط قبل الانتقال لما بعدها.
