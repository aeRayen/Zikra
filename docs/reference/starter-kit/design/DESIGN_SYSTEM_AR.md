# نظام التصميم وتجربة الاستخدام

## الاتجاه البصري
- هوية هادئة وراقية، وليست مزدحمة أو طفولية.
- أخضر زمردي وألوان داكنة، درجات عاجية، ولمسات ذهبية محدودة.
- دعم Light / Dark themes.
- بطاقات بسيطة وحدود هادئة ومساحات تنفس واضحة.
- RTL افتراضي للعربية، مع اختبار الأرقام والتواريخ وعلامات الترقيم.
- الخط العربي قابل للتكبير، مع تباين وإتاحة مناسبين.

## التنقل المقترح
1. اليوم
2. العبادة
3. القرآن
4. المكتبة
5. الحماية
6. التعافي
7. المنبه
8. الإعدادات

يمكن أن تظهر أهم الأقسام في شريط تنقل سفلي محدود، والباقي داخل مركز واضح أو صفحة المزيد. لا تضع 8 عناصر صغيرة في شريط سفلي واحد.

## لوحة اليوم
- الصلاة القادمة والوقت المتبقي.
- مدخل سريع للقرآن والورد.
- الأذكار حسب الوقت.
- حالة المنبه القادم.
- بطاقة تركيز أو عادة واحدة يختارها المستخدم.
- لا تعرض بيانات حساسة على شاشة مشتركة أو إشعار افتراضيًا.

## قواعد UX
- كل صلاحية تُطلب عند الحاجة مع شرح السبب.
- لا تستخدم الخوف أو الإحراج في رسائل التعافي.
- لا تجعل استعادة الحساب أو إيقاف المراقبة عملية مضللة.
- اعرض حالات Offline وSync بوضوح.
- كل شاشة تشمل Loading / Empty / Error عند الحاجة.
- وفّر إمكانية الوصول وتكبير الخط ودعم قارئ الشاشة.
- تجنب الزخارف الثقيلة التي تؤثر على الأداء.
