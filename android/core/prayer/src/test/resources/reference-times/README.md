# Reference prayer times (golden data)

Copied unchanged from [batoulapps/adhan-js `Shared/Times`](https://github.com/batoulapps/adhan-js/tree/master/Shared/Times)
(MIT License, © Batoul Apps), retrieved 2026-10-15. Each file lists its official source
(e.g. ummulqura.org.sa, Diyanet, Qatar/Kuwait/Dubai/Singapore/Tehran authorities, Moonsighting
Committee), the calculation parameters and, where the authority rounds differently, an allowed
`variance` in minutes. `PrayerReferenceTest` checks every listed day against our engine.
