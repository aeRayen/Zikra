# ذِكْرَى — Zikra

تطبيق إسلامي متكامل يعمل على الجهاز أولًا، ويدعم جميع اللغات.

*A local-first, multilingual Islamic companion app.*

| | |
|---|---|
| المعرّف | `com.zikra.app` |
| المنصة | Android (Kotlin, Jetpack Compose) — iOS لاحقًا |
| الحسابات (اختيارية) | Supabase |
| الحالة | **المرحلة 1 — التأسيس** (لا توجد ميزات منفذة بعد) |

## خريطة المستودع

| المسار | المحتوى |
|---|---|
| `docs/plan/BUILD_PLAN_AR.md` | خطة البناء بالمراحل وحزم العمل |
| `docs/adr/ADR_LOG_AR.md` | سجل القرارات المعمارية |
| `docs/specs/` | مواصفات المرحلة 0b: اللغات، والمزامنة، وحزم المحتوى، وSupabase، والتصميم، والاختبار |
| `docs/audit/` | تقرير تدقيق المرحلة 0 |
| `docs/reference/starter-kit/` | حزمة الفكرة الأصلية (للمرجع فقط، **لا تُعدَّل**) |
| `android/` | تطبيق Android (من الحزمة 1.2) |
| `supabase/` | ترحيلات قاعدة البيانات ودوالها (من الحزمة 1.9) |
| `tools/content-pipeline/` | أداة بناء حزم المحتوى (الحزمة 1.15) |

> **ملاحظة:** الوثائق المنقولة من `phase-0b/` صارت في `docs/specs/`، وسجل القرارات صار في `docs/adr/`. الإشارات القديمة إلى `phase-0b/...` داخل الوثائق تعني `docs/specs/...`.

## قواعد أساسية

- اقرأ [CONTRIBUTING.md](CONTRIBUTING.md) قبل أي تغيير.
- **لا أسرار في git.** انسخ `.env.example` إلى `.env` محليًا.
- **لا نص ديني من غير مصدر مرخص**، ولا ترجمة آلية لنص ديني.
- **لا ميزة «مكتملة» دون اختبارات ناجحة.**
